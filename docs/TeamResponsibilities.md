# SyncCanvas Project Ownership & Architecture

**Project Owner & Lead Developer:** Anshul

## Modules & Architecture Ownership
- **Full Stack Architecture & Integration:** End-to-end setup, build tooling, monorepo orchestration, and cross-platform deployment.
- **Collaborative Whiteboard Engine:** React-Konva infinite canvas, vector drawing tools, shape manipulation, state synchronization, and cursor tracking.
- **Multiplayer Monaco Code Editor:** Monaco Editor integration, syntax highlighting for multi-language execution, Yjs CRDT synchronization, and local multi-language execution runner.
- **Backend API & Real-time Services:** Express.js REST API, Socket.io real-time gateways, Yjs binary document sync, and room state lifecycle management.
- **Authentication & Database Architecture:** MongoDB with Mongoose, JWT authentication, cookie-based session handling, role-based access control, and built-in embedded fallback database for zero-config startup.
- **UI & UX Engineering:** Modern dark-mode interface, responsive dashboard, room controls, participant management, and real-time collaboration panels.
